# HOT POT — Neon Overdrive

Pixelartowa bijatyka w restauracji, w stylu Tibii. Cała gra mieści się w jednym pliku HTML.

**Zagraj:** https://id94.github.io/Hot-Pot-/

## Sterowanie
| Klawisz | Akcja |
|---|---|
| WASD | ruch |
| Shift | bieg |
| J | pięści (combo x3) |
| K | kopnięcia (combo x3) |
| L | blok |
| I | chwyć / rzuć |
| R | powtórz poziom |
| Esc | menu |
